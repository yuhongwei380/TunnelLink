2. 使用范围与授权

3. 系统与网络变更
Windows 安装程序需要管理员权限，会安装或检查随包提供的 TAP 虚拟网卡驱动。macOS 使用系统提供的 utun 接口，连接时需要授权网络配置操作。连接 VPN 会根据服务器配置调整路由和 DNS；连接或断开期间网络可能短暂中断。卸载客户端会保留可能被其他软件共享的 Windows TAP 驱动。

4. 凭据、设置与日志
用户名及密码用于向您配置的 VPN 服务进行认证。选择“在此设备记住凭据”后，成功认证的凭据由操作系统凭据存储保存（Windows Credential Manager / macOS Keychain）。请勿在共享设备上启用此选项。取消该选项并成功连接后，客户端会删除此前保存的凭据。
语言偏好保存在本机。客户端维护本次运行的诊断日志；日志可能包含网关地址、用户名、证书信息或其他网络信息。客户端会尝试遮蔽密码，但分享或复制日志前仍请检查敏感内容。本客户端没有内置向项目开发者发送诊断日志的功能。VPN 服务端的数据处理规则由其运营方另行提供。

Connect only to VPN gateways you are authorized to access. Follow applicable laws and your organization's network policies. Your administrator supplies accounts, access rights, and server policies. This client does not provide accounts or guarantee server availability.

3. System changes
Windows installation requires administrator privileges and installs or checks the bundled TAP virtual network adapter driver. macOS uses the system utun interface and requests authorization for network configuration when connecting. VPN connections can change routes and DNS according to server settings and can briefly interrupt connectivity. Uninstalling the Windows client retains the potentially shared TAP driver.

4. Credentials and diagnostics
Credentials authenticate to your configured VPN service. If you select Remember credentials, successfully authenticated credentials are stored in Windows Credential Manager or macOS Keychain. Avoid this option on shared devices. A successful connection with this option disabled deletes previously saved credentials. Language preferences are local. Session diagnostics may contain gateway addresses, usernames, certificate details, or network information. The client attempts to redact passwords; check logs before sharing them. There is no built-in feature sending diagnostics to this project's developers. The VPN operator's separate data policies apply to its service.
