# Tunnel Link

Tunnel Link 是面向 Windows 和 macOS 的虚拟专网加密隧道客户端，用于连接授权专网并访问内部业务资源，支持账号登录、中英文界面、系统凭据存储和连接日志。客户端基于 OpenVPN 3 Core 二次开发，是独立的非官方客户端。

## 安装

- **Windows 10/11 x64**：运行对应版本的安装程序，按提示完成安装并允许管理员授权。安装包包含 VPN 引擎和 TAP 驱动，无需另装 OpenVPN Connect。缺少 WebView2 时，默认安装程序需要联网安装该运行时。
- **macOS 13.3 及以上**：打开与芯片架构匹配的 DMG，将应用拖入“应用程序”，再从“应用程序”或 Launchpad 启动。若直接双击 DMG 中的应用，客户端首次打开会提示“复制到‘应用程序’”，点击确认即可自动复制并重新打开；也可以选择稍后处理。首次启动还需阅读并同意用户协议，建立连接时按系统提示授权。

安装完成后即可使用，用户电脑不需要安装 Node.js 或 Rust。账号和网关访问权限由提供客户端的管理员分配。

## 统一打包流程

需要生成带私有 VPN 配置的安装包时，使用仓库根目录的统一入口：

1. 安装 Node.js 22 或更新版本，并将完整、内嵌证书的配置保存为 `custom-config/client.ovpn`，配置要求见[自定义构建配置](custom-config/README.md)。
2. 在 Windows x64 或 macOS（Apple Silicon / Intel）本机执行 `node build.mjs`。
3. 入口会检查平台、增量同步当前源码和配置，优先复用已校验的本地引擎、依赖及编译缓存；缓存缺失或不匹配时才下载和编译。产物只保存到 `build_dist/<平台>/`（重复构建覆盖同名安装包，构建缓存中不留安装包副本）。

只准备源码和配置、不安装依赖或编译时执行 `node build.mjs --prepare-only`。已有工具链希望完全手动管理时，加上 `--no-auto-install-deps`；强制或跳过引擎编译分别使用 `--force-engine` 和 `--skip-engine`。私有配置会编译进客户端，请不要把 `custom-config/client.ovpn` 或生成的 `build_dist/` 内容提交到 Git。

统一构建优先使用 `custom-config/app-branding.json`，在隔离构建目录中覆盖 `resources/settings/app-branding.json`。修改其中 `defaultLocale` 为 `CN` 或 `EN` 后重新构建，即可生成不同默认语言的安装包；手动切换过语言的用户仍使用其保存的选择。若该文件不存在，则使用 `resources/settings/app-branding.json`。

`custom-config/` 保存本地构建输入，`resources/settings/` 保存仓库默认配置与依赖版本锁；前端和 Tauri 原生后端统一位于 `ui/`。`node build.mjs` 构建安装包，`npm run build` 只构建前端静态文件。目录职责与分步构建命令见[开发指南](docs/development.md#代码目录)和[构建与发布](docs/building.md)。

客户端保留真实服务器域名和 IP 展示；密码和私钥仍需保护。旧 `log-privacy.json` 的非空 `endpointAlias` 已停用，构建前请移除或设置为 `null`。

## 连接和断开

1. 打开客户端，点击“连接 Internal Tunnel”。
2. 输入企业用户名和密码。密码区分大小写；若出现大写锁定或首尾空格提示，请检查后再提交。
3. 如需在当前设备保存账号密码，勾选“在此设备记住凭据”，然后点击“登录并连接”。
4. 等待状态显示“已连接”。正在连接时可点击“取消连接”，连接成功后可点击“断开连接”。
5. 如需使用其他账号，点击连接卡片中的“切换用户”。填写新账号并确认“登录并连接”后才会断开当前连接；取消登录会保留原连接。

在连接页选择配置后再连接。同一时间只允许一个连接，切换配置前必须先断开。启用导入的版本可添加多个 `.ovpn`，在原生文件选择器中补选外部 CA、客户端证书或未加密私钥；材料会保存为独立副本，原文件移动不影响使用。管理入口支持重命名和删除导入配置，内置配置只读。仅证书认证不弹出账号密码框。

内置名称和说明由构建配置提供，未指定名称时使用 `Internal Tunnel`；不会自动标记为 Demo。三个发行组合及示例见[构建开关](docs/building.md#客户端配置功能)。

会话时长从隧道连接成功后开始计算；流量统计在引擎提供有效计数后显示。

## 保存凭据

“记住凭据”默认关闭。启用后，账号密码按配置身份及内容版本隔离，仅在认证成功后保存到 Windows 凭据管理器或 macOS 钥匙串。取消勾选并成功连接后，会删除已保存的凭据。

从旧客户端升级后，需要重新输入一次账号密码。密码显示按钮只影响当前输入框的可见性，不会修改密码内容。

## 查看日志

点击左侧“日志”，可以：

- 查看最近的连接事件，按关键词搜索或只显示错误事件。
- 刷新或清空运行日志。
- 暂停自动刷新以查看当前日志，搜索、筛选、复制与手动刷新仍可使用；点击“恢复刷新”继续实时更新。关闭后重新打开日志会恢复自动刷新。
- 复制当前筛选结果；复制内容包含全部匹配事件，不限于窗口中最近显示的条目。
- 选择最近 5 分钟、30 分钟或 1 小时，将已脱敏日志导出为系统“下载”目录中的 `.log` 文件。

连接失败时，请把相关错误提供给管理员。日志可能包含网络信息，分享前可先检查内容。

## 窗口与语言

右上角可切换中文和英文。桌面窗口固定为 840 × 640（横向布局），不支持调整大小及最大化。

需要暂时收起窗口并保留连接时，使用标题栏的最小化按钮。关闭窗口会弹出退出确认；“继续使用”返回客户端，“退出”会停止连接并关闭应用。

## 修改连接页文案

客户端首次启动时，会把 [`resources/settings/ui-copy.json`](resources/settings/ui-copy.json) 的默认内容复制到操作系统的用户配置目录：

- Windows：在资源管理器地址栏打开 `%APPDATA%\com.example.openvpn-client-phoenix`。
- macOS：在 Finder 中按 `Command + Shift + G`，前往 `~/Library/Application Support/com.example.openvpn-client-phoenix`。

编辑其中的 `ui-copy.json`，保存后重启客户端即可看到修改。应用只在该文件还不存在时创建默认文件，不会覆盖你的修改。

`zh` 和 `en` 分别对应中文和英文。`appTitle` 控制界面顶部应用名称，`copyright` 控制连接页底部版权信息；`overview` 控制连接页顶部的小标题、主标题与简介；`connection` 控制深蓝连接卡片上的连接说明、连接按钮、各个连接状态的标题与简介，以及登录提示。换行请写作 `\n`。请保留字段名，并确保文件仍为合法 JSON；如果文件暂时无法解析，客户端会使用内置默认文案，修正后重新启动即可。

默认应用名称为 Tunnel Link，底部显示“©2026 Power by Openvpn3 Core”，OpenVPN 的技术来源、商标归属及开源许可说明保留在“关于软件”中。用户可通过 `ui-copy.json` 自定义应用名称和底部文案。

文案只包含纯文本，不会解析 HTML 或脚本内容。

## 常见问题

- **连接失败或一直连接中**：检查网络与账号密码，在日志中查看具体错误，并联系管理员确认网关和账号权限。
- **提示 Windows 适配器无法打开**：关闭其他 VPN 连接后重试；仍失败时，重新运行本客户端安装程序修复内置 TAP 驱动。
- **提示路由或 DNS 权限不足**：在系统授权提示中允许所需权限。
- **Windows 安装驱动失败**：查看安装目录中的 `driver-install.log`，把错误信息提供给维护人员。

## 卸载与凭据清理

- **Windows**：可在已安装客户端的“关于软件”中点击“卸载并清除数据…”，也可通过系统“已安装的应用”卸载。应用内入口会先显示二次确认；确认后断开连接并调用正式卸载程序。卸载程序会删除当前 Windows 账户在凭据管理器中保存的登录凭据，以及 Roaming/Local 下本应用的设置和缓存；清理失败会停止卸载并提示重试。使用 `/UPDATE` 的更新替换会保留全部用户数据。共享 TAP 驱动与适配器继续保留，避免影响其他软件。
- **macOS**：在已安装客户端的“关于软件”中点击“卸载并清除数据…”，核对二次确认框中的清理范围，点击“确认卸载并清除”。程序会断开连接、清除当前 Mac 用户钥匙串中的登录凭据，将应用移入废纸篓，并在退出后清理界面设置、自定义文案、协议记录和应用缓存。取消确认不会断开连接或删除数据；卸载执行时会禁止重复操作。

macOS 直接把应用拖入废纸篓不会运行数据清理，请使用上述应用内入口；正常使用时仍支持跨重启记住凭据。清除的凭据和设置无法通过恢复或重新安装应用找回。凭据清理失败或应用无法移入废纸篓时，会在确认框中提示；退出后的数据清理失败会弹出系统提示。系统凭据存储按操作系统账户隔离；同一设备如有多个账户使用过客户端，应分别清理各自的数据。
